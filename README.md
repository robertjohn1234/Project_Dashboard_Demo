# Project Dashboard (portfolio demo)

A demo of my internal project dashboard. All data is made up (see demo-data.js); no company data is included.

Built with Node + Express, Chart.js and plain HTML/CSS/JS. It has a cable-progress page, S-curve, daily activities, LV categories, a home page with a bulletin board, and a small animation layer (fx.js) with a "Present" mode.

Run locally:   npm install   then   npm start   and open http://localhost:3000
Deploy:        Render > New > Web Service > this repo. Build: npm install   Start: npm start
